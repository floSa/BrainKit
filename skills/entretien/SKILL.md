# Entretien — enveloppe

Ce fichier n'est **qu'une enveloppe**. Le contenu est dans une recette en
Markdown pur, lisible par n'importe quel agent de code :

**[`recettes/mener-l-entretien.md`](../../recettes/mener-l-entretien.md)**

Lis-la maintenant, en entier, et suis-la. Rien n'est écrit ici qui n'y soit :
une seconde version du contenu prendrait du retard sur la première, et c'est
exactement le défaut que ce kit existe pour supprimer.

Le contexte général du dépôt — ce qu'on peut faire, ce qu'on ne fait jamais, où
sont les autres recettes — est dans [`AGENTS.md`](../../AGENTS.md).
