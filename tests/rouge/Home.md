# Épreuve — le vault ROUGE

Le jumeau fautif du vault vert. Il porte SEPT défauts, un par mécanisme sous
test, et rien d'autre : tout le reste — les hubs, l'atteignabilité, les
étiquettes fermées, la couverture des sections, la réinjection du résumé — est
correct, pour que le verdict ne mesure que ce qu'il prétend mesurer.

Les sept défauts sont énumérés, avec la règle attendue, dans `tests/epreuve.py`.

## Les périodes

- [[Antiquité]] — jusqu'à 476
- [[XXe siècle]] — après 1914
- [[Transversal]] — les synthèses de longue durée, sans centre de gravité
