# Kennan - Le long telegramme

## Ce que c'est

**DÉFAUT 3 — le cas qui ÉCHOUE pour le PRÉFIXE TRANSVERSAL.** La page porte
`transversal` ET `xxe`, et vit dans `XXe siècle/`. Le préfixe transversal
l'emporte : le dossier attendu est `Transversal/`. Attendu : un constat DUR de
`chemin_categorie` qui nomme le préfixe et le dossier visé.

Sans cette priorité, la règle de majorité accepterait `XXe siècle/` — puisque
`xxe` est bien une valeur portée — et le préfixe transversal ne servirait à
rien.
