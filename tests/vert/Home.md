# Épreuve — la porte d'entrée

La racine n'est pas un dossier de pages : le périmètre s'énumère par la négative,
et un `.md` posé ici n'est donc pas contrôlé comme une page. C'est en revanche
d'ici que partent les hubs de premier niveau, qui n'ont aucun parent pour les
citer — sans cette porte, quatre d'entre eux seraient injoignables.
